GAME INTRODUCTION

游戏介绍

《万界道友》是一款以 AIGC 驱动、高自由度文字体验和长期成长为核心的修仙游戏。这里先建立清晰的产品认知，后续再逐步补充完整世界设定。

核心定位

世界观

你将以一名初入道途的修士入世，在洞府修行、坊市交易、秘境探险、天骄争锋和诸多奇遇之间寻找自己的成道路。这个世界不只看境界高低，也看命数、灵根、功法、神通、法宝、丹药和一次次选择如何交织。

核心循环

每天的成长围绕“修炼积累 -> 获取资源 -> 打造构筑 -> 挑战更高目标”展开。闭关推进修为，副本带来材料与机缘，坊市补齐短板，造物把资源转化成法宝和丹药，排行榜与高阶副本则检验你的阶段战力。

AIGC 特色

AI 会参与角色设定、命格命名、功法神通描述、副本场景和战斗播报，让同一套规则生成更多不同的修仙故事。核心数值和资源变化仍由游戏规则把关，保证奇遇有变化，成长有边界。

文字修仙定位

《万界道友》更重视长期养成、策略取舍和文字想象。它不是短平快的闯关游戏，而是一段可以慢慢规划、反复调整、逐步形成个人道途的修仙旅程。
