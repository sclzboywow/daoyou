系统说明

基础设定一览

快速了解道具品阶、境界层次、角色设定和主要玩法入口。

这篇资料适合刚入世的道友快速查阅。你可以先不用记住所有细节，只要知道每个设定大概影响什么，后续看到装备、丹药、功法、境界和玩法入口时就不会迷路。

道具品阶

游戏中常见道具会用“品阶”表示稀有度和大致价值。品阶从低到高通常为：

凡品 -> 灵品 -> 玄品 -> 真品 -> 地品 -> 天品 -> 仙品 -> 神品

品阶越高，通常代表潜力、数值或稀有度越高，但不等于一定适合当前角色。新手尤其要注意三点：

  • 看用途：突破丹、恢复丹、炼体材料、炼器材料的价值不在同一个维度。
  • 看阶段：高品道具可能很强，但当前境界未必能完全发挥。
  • 看构筑：与你灵根、功法、神通方向契合的道具，往往比单纯高品更有用。

功法和神通还可能使用另一套阶位表达，例如黄阶、玄阶、地阶、天阶，并细分上品、中品、下品。理解方式类似：阶位代表基础评价，最终仍要看效果是否适合你。

境界一览

角色修行从低到高依次经历：

炼气 -> 筑基 -> 金丹 -> 元婴 -> 化神 -> 炼虚 -> 合体 -> 大乘 -> 渡劫

每个大境界又分为：

初期 -> 中期 -> 后期 -> 圆满

境界决定角色所处的成长阶段。境界提升后，角色可以承受更高难度挑战，也会接触更高价值的资源、丹药、法宝和副本目标。

突破前建议先确认修为、感悟、当前状态和辅助丹药。准备不足时强行冲关，可能会浪费资源，也可能让角色进入不利状态。

角色有哪些设定

角色不是只有等级和战力。下面这些设定会共同决定你的修仙路线。

名号、性别、出身与性格

这些更偏角色扮演和叙事表达，会影响你对角色的代入感，也会出现在角色介绍、背景描述或生成文本中。

境界与阶段

境界是最直观的成长层级。它决定你当前属于哪个修行阶段，也影响副本选择、榜单分组和资源规划。

年龄与寿元

年龄记录角色修行经历，寿元代表可继续修行的时间余量。长期闭关、突破和成长节奏都要考虑寿元压力。

五项基础属性

  • 体魄：影响耐久、承伤和气血相关表现。
  • 灵力：影响法术强度、法力和神通释放基础。
  • 悟性：影响理解、命中、暴击和参悟方向。
  • 速度：影响出手节奏、闪避和战斗先机。
  • 神识：影响抗性、暴击对抗和精神层面的稳定性。

这五项是角色最核心的基础属性。很多战斗表现会由它们进一步体现出来，所以不要只看一个总战力数字。

灵根

灵根代表角色与金、木、水、火、土、风、雷、冰等属性的契合程度。灵根越贴合你的主要神通和功法，越容易形成稳定路线。

先天命格

命格是角色开局携带的气运。它可能提升闭关、突破、恢复、炼丹、炼器或灵石收益，也可能带来代价。选择命格时，不要只看名字华丽，要看收益和负担是否适合你的玩法。

功法与神通

功法偏长期根基和被动加成，神通偏战斗中的实际手段。角色强不强，往往取决于功法、神通、灵根和属性是否互相配合。

法宝、丹药、材料与灵石

法宝用于提升战斗或提供特殊能力；丹药用于恢复、修炼、突破、炼体等关键节点；材料用于炼丹炼器和其他造物；灵石则是交易、炼制和许多玩法的基础资源。

声望与排行榜

声望体现角色在修仙界中的名望，也和榜单、奖励、宝阁等目标相关。想追求竞争和展示，可以关注天骄榜与物品榜。

当前状态

角色会记录当前气血、法力、丹毒、伤势或其他长期状态。副本、战斗、丹药和恢复都会影响状态。状态不好时，先恢复再挑战通常更稳。

有哪些主要玩法

修炼与闭关

修炼是推进境界的主线。通过闭关积累修为和感悟，准备充分后尝试突破。

境界突破

突破用于进入更高阶段。它需要修为、感悟和状态配合，也可以借助丹药等手段提高把握。

悟道与功法神通

悟道用于获取或推演功法神通。你可以围绕灵根和战斗目标，逐步形成自己的构筑。

炼丹

炼丹把药材和其他材料转化为丹药。丹药可以恢复气血法力、辅助修炼突破、推进炼体或处理特殊状态，但也要注意丹毒和使用限制。

炼器

炼器把材料转化为法宝。法宝会影响角色战斗表现，适合用来补输出、防护、速度、抗性或特殊效果。

副本探索

副本是获取材料、灵石、修为、感悟和奇遇的重要来源。进入前要看境界门槛、难度和角色状态。

坊市交易

坊市用于购买材料、珍宝和神秘货物，也可以通过鉴宝与回收处理背包资源。缺什么资源时，坊市往往是最直接的补齐入口。

排行榜与挑战

排行榜提供阶段性目标。天骄榜看角色战力，物品榜展示优秀法宝、功法、神通和丹药。想检验构筑时，可以关注榜单和挑战入口。

任务、传音与社区

任务中心帮助你明确当前目标；传音玉简承接系统消息和奖励；世界传音与玩家交流群则用于交流心得、反馈问题和分享构筑。

AI 奇遇

AI 会参与角色设定、命格命名、功法神通描述、副本场景和战斗播报，让文字体验更有变化。核心资源和数值仍以游戏规则为准。

新手阅读建议

第一次游玩时，不必一次理解所有系统。建议先按这个顺序熟悉：

  1. 创建角色，了解灵根、命格和五项基础属性。
  2. 闭关修炼，体验境界阶段和突破。
  3. 进入副本，获取第一批材料和资源。
  4. 尝试炼丹、炼器，把资源转化为战力。
  5. 再去调整功法神通，开始规划自己的构筑。
